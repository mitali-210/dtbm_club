Design a premium cinematic website UI in Figma for a running community called DTBM Run Club.

The design should feel like a Nike running campaign mixed with Apple product design.

The UI must be minimal, dark, athletic, futuristic, and extremely premium with smooth interactions and immersive visuals.

The goal is to create a digital hub for runners where they can explore events, register for races, track stats, and experience the energy of the running community.
